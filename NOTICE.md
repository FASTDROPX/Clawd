Python-модуль содержит исходное указание: «Clawd sprites and movement, adapted from clawd_pet 1.5 by @itskotovski». Оно сохранено без изменений. Переданная версия README также указывает @itskotovski как автора исходного плагина.

## Оформление репозитория

Обложка docs/assets/clawd-hero.png создана с помощью ИИ для Clawd по визуальным референсам: терракота, молочная бумага, шалфейные акценты и рисованные линии. Присланные референсы не включены в репозиторий. Обложка — стилизованная иллюстрация, не изображение реального интерфейса.
